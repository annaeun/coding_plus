# 온기 다이어리

매일 한 줄 일기와 이달의 습관을 함께 기록하는 다이어리입니다. 왼쪽 페이지에는 하루하루의 짧은 일기를, 오른쪽 페이지에는 이번 달 습관 체크와 그 결과(습관 온도·습관 그래프)를 남깁니다.

바로 열어보기: [온기 다이어리 ](https://github.com/annaeun/coding_plus/blob/main/ongi_diary/ongidiary.html)

## 화면 구성

### 왼쪽 페이지 — 한 줄 일기
- 위쪽에 현재 월이 큰 숫자와 영문으로 표시됩니다.
- 날짜별로 한 줄(최대 50자)씩 그날의 기록을 적을 수 있습니다.
- 토요일·일요일은 분홍색으로 구분됩니다.

### 오른쪽 페이지 — 이달의 습관
- **이달의 습관**: 이번 달에 지킬 습관을 최대 8개까지 입력합니다. (예: 물 2L, 운동, 독서)
- **체크박스**: 매일 그 습관을 실행했으면 해당 칸을 눌러 체크합니다.
- **습관 온도**: 그날 체크한 습관 수를 100도 기준으로 환산해 숫자로 보여줍니다. 온도가 높을수록 노란색에서 빨간색으로 바뀝니다.
- **습관 그래프**: 그날 체크한 습관 개수에 해당하는 칸에 ⭐가 표시되고, 매일의 별이 빨간 선으로 이어져 한 달의 흐름을 한눈에 볼 수 있습니다.

## 사용법

1. 상단의 `‹` `›` 버튼으로 월을 이동하고, `오늘` 버튼으로 현재 월로 바로 돌아갑니다.
2. 오른쪽 페이지 위쪽의 습관 입력칸에 이번 달 습관 이름을 적습니다. (세로로 표시됩니다)
3. 매일 왼쪽 페이지에 한 줄 일기를 쓰고, 오른쪽 페이지에서 그날 실행한 습관에 체크합니다.
4. 입력한 내용은 자동으로 저장되며, 상단에 "저장됨" 표시가 뜹니다. 다음에 다시 열어도 그대로 남아 있습니다.

## 알아두면 좋은 점

- 습관 이름을 비워두면 해당 칸의 체크박스는 비활성화되고, 습관 온도·그래프 계산에서도 제외됩니다.
- 습관을 하나도 입력하지 않은 달에는 오른쪽 페이지에 안내 문구가 표시됩니다.
- 밝은 화면/어두운 화면(다크 모드) 모두 지원합니다.
