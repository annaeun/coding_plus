# 🌱 Daily Lang_study

매일 조금씩, 단어 · 문법 · 회화 · 듣기를 한 바퀴씩 돌며 언어를 공부하는 웹 앱입니다.
서버나 빌드 과정 없이 HTML 파일 하나만 열면 바로 사용할 수 있어요.

## 💻 바로가기

👉 [언어 공부 프로그램 바로가기](https://langtutor-d9342.web.app/lang_tutor.html)

## 파일 구성

이 저장소에는 목적이 다른 두 개의 앱 파일이 있습니다.

| 파일 | 설명 |
|---|---|
| `index.html` | 전체 기능 버전. 학습 언어 7개(영어·일본어·중국어·스페인어·프랑스어·한국어·태국어), 인터페이스 언어 8개를 모두 지원합니다. AI 연동 없이 모든 콘텐츠가 파일 안에 고정되어 있어요. |
| `lang_tutor.html` | 축소 버전. 인터페이스 언어는 한국어·영어, 학습 언어는 영어·스페인어·태국어를 제공합니다. Google 로그인(Firebase Auth) + Firestore 클라우드 동기화, Gemini API 연동(학습 콘텐츠 자동 생성, 회화 채점, AI 대화 연습)이 적용된 파일입니다. |

두 파일 모두 완전히 독립적으로 동작하는 단일 HTML 파일이며, 외부 라이브러리나 빌드 도구가 필요 없습니다.

## 주요 기능

- **오늘 학습할 언어 선택**: 홈 화면에서 언어와 학습 레벨(입문/중급/고급)을 고를 수 있어요.
- **오늘의 학습 4가지**
  - 📖 **단어(Vocabulary)**: 플래시카드로 단어를 익히고, 예문 빈칸 채우기로 복습
  - 📝 **문법(Grammar)**: 문법 패턴과 예문을 학습하고, 빈칸 채우기로 복습
  - 💬 **회화(Conversation)**: 상황별 표현을 학습하고, 질문에 직접 답을 입력해보며 복습
  - 🎧 **듣기(Listening)**: 문장을 단계적으로 들으며 표현·해석을 확인하고, 객관식 문제로 복습
- **오늘의 진행률**: 4가지 학습을 마칠 때마다 홈 화면의 진행률 바가 채워져요.
- **진행률(Progress) 탭**: 연속 학습일(streak), 학습한 단어 수, 정답률, 학습 시간, 최근 7일 학습량 그래프를 확인할 수 있어요.
- **발음 듣기**: 브라우저 내장 음성 합성(Web Speech API)으로 단어·문장을 들을 수 있어요. 별도 API 연동이 필요 없어요.
- **다국어 인터페이스**: 화면 오른쪽 위 국기 버튼으로 인터페이스 언어를 바꿀 수 있어요.
- **모바일 대응**: 화면이 좁아지면 언어·레벨 선택이 드롭다운으로 바뀌고, 하단에 탭 내비게이션이 나타납니다.
- **(`lang_tutor.html` 전용) Google 로그인 & 클라우드 동기화**: 설정 화면에서 Google 계정으로 로그인하면 학습 진행률·설정이 Firestore에 저장되어 PC·모바일 등 여러 기기에서 이어서 학습할 수 있어요.
- **(`lang_tutor.html` 전용) AI 학습 콘텐츠 생성**: 설정 화면에 본인의 Gemini API 키를 입력하면, 선택한 언어·레벨에 맞춰 단어·문법·듣기 콘텐츠를 AI가 새로 생성해요. 하루 최대 3개 버전까지 생성하고, 이후 접속에서는 그 중 하나를 랜덤으로 재사용해요.
- **(`lang_tutor.html` 전용) AI 회화 채점 & 연습**: 회화 복습에서 답을 입력하면 AI가 정답 여부와 피드백을 함께 알려주고, 복습이 끝나면 그날 배운 표현으로 짧은 AI 대화 연습(최대 4턴)을 이어갈 수 있어요. 🎤 버튼으로 음성 입력도 가능해요.

## 사용 방법

1. `index.html` 또는 `lang_tutor.html` 파일을 더블클릭해서 브라우저로 열거나, 로컬 서버로 실행합니다.
   ```bash
   python3 -m http.server 8934
   ```
   위 명령을 실행한 뒤 `http://localhost:8934/index.html` (또는 `lang_tutor.html`)로 접속합니다.
2. 홈 화면에서 오늘 공부할 **언어**와 **레벨**을 선택합니다.
3. "오늘의 학습" 카드 중 하나(단어/문법/회화/듣기)를 눌러 학습을 시작합니다.
4. 각 학습을 끝까지 마치면 자동으로 복습 문제로 넘어가고, 복습까지 끝나면 완료 표시와 함께 축하 메시지가 나타납니다.
5. 4가지를 모두 마치면 홈 화면 진행률이 100%가 되고, 진행률 탭에서 학습 기록을 확인할 수 있어요.

## 데이터 저장 방식

- `index.html`: 모든 학습 진행 상황(선택한 언어, 레벨, 오늘 완료한 항목, streak, 학습 통계 등)이 브라우저의 `localStorage`에만 저장됩니다. 다른 브라우저나 기기에서 열면 처음부터 다시 시작해요.
- `lang_tutor.html`: 기본은 `localStorage`에 저장되고, Google 로그인을 하면 같은 데이터가 Firestore에도 동기화되어 로그인한 다른 기기에서도 이어서 볼 수 있어요. 단, **Gemini API 키와 그 키로 생성된 AI 콘텐츠 캐시는 기기별 `localStorage`에만 저장**되며 로그인 계정을 통해 동기화되지 않아요.
- 날짜가 바뀌면 오늘의 진행률과 완료 표시는 자동으로 초기화되고, streak은 어제도 학습했는지에 따라 유지되거나 초기화됩니다.

## AI 기능 사용법 (`lang_tutor.html`)

1. 우측 상단 설정에서 **Google 로그인**을 하면 여러 기기 간 학습 기록이 동기화됩니다 (선택 사항).
2. **AI 설정** 화면에 [Google AI Studio](https://aistudio.google.com/apikey)에서 발급받은 본인의 Gemini API 키를 입력합니다. 키는 그 브라우저에만 저장되고 서버로 전송되지 않아요.
3. 키를 등록하면 단어·문법·듣기 콘텐츠가 매일 최대 3개 버전까지 AI로 새로 생성되고, 회화 복습은 AI가 채점 및 피드백을 제공하며, 복습 후 짧은 AI 회화 연습이 이어집니다.
4. 키가 없으면 자동으로 파일에 고정된 정적 콘텐츠로 대체되어 이전과 동일하게 동작합니다.

## 기술 스택

- HTML5 / CSS3 / Vanilla JavaScript (프레임워크 없음)
- Web Speech API (브라우저 내장 음성 합성 · `lang_tutor.html`의 음성 인식)
- Firebase Authentication (Google 로그인), Cloud Firestore (`lang_tutor.html`)
- Google Gemini API (`lang_tutor.html`의 AI 콘텐츠 생성 · 회화 채점 · 대화 연습)
- Firebase Hosting (배포)
