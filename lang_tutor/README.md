# 🌱 Daily Lang_study

매일 조금씩, 단어 · 문법 · 회화 · 듣기를 한 바퀴씩 돌며 언어를 공부하는 웹 앱입니다.
서버나 빌드 과정 없이 HTML 파일 하나만 열면 바로 사용할 수 있어요.

## 💻 바로가기

👉 [언어 공부 프로그램 바로가기](https://langtutor-d9342.web.app/lang_tutor.html)

## 파일 구성

이 저장소에는 목적이 다른 두 개의 앱 파일이 있습니다.

| 파일 | 설명 |
|---|---|
| `index.html` | 전체 기능 버전. 학습 언어 7개(영어·일본어·중국어·스페인어·프랑스어·한국어·태국어), 인터페이스 언어 8개를 모두 지원합니다. AI 연동 없이 모든 콘텐츠가 파일 안에 고정되어 있어요. |
| `lang_tutor.html` | 축소 버전. 인터페이스 언어는 한국어·영어, 학습 언어는 영어·스페인어만 제공합니다. 개인용으로 Claude API · Firebase 로그인 연동을 진행할 예정인 파일입니다. |

두 파일 모두 완전히 독립적으로 동작하는 단일 HTML 파일이며, 외부 라이브러리나 빌드 도구가 필요 없습니다.

## 주요 기능

- **오늘 학습할 언어 선택**: 홈 화면에서 언어와 학습 레벨(입문/중급/고급)을 고를 수 있어요.
- **오늘의 학습 4가지**
  - 📖 **단어(Vocabulary)**: 플래시카드로 단어를 익히고, 예문 빈칸 채우기로 복습
  - 📝 **문법(Grammar)**: 문법 패턴과 예문을 학습하고, 빈칸 채우기로 복습
  - 💬 **회화(Conversation)**: 상황별 표현을 학습하고, 질문에 직접 답을 입력해보며 복습
  - 🎧 **듣기(Listening)**: 문장을 단계적으로 들으며 표현·해석을 확인하고, 객관식 문제로 복습
- **오늘의 진행률**: 4가지 학습을 마칠 때마다 홈 화면의 진행률 바가 채워져요.
- **진행률(Progress) 탭**: 연속 학습일(streak), 학습한 단어 수, 정답률, 학습 시간, 최근 7일 학습량 그래프를 확인할 수 있어요.
- **발음 듣기**: 브라우저 내장 음성 합성(Web Speech API)으로 단어·문장을 들을 수 있어요. 별도 API 연동이 필요 없어요.
- **다국어 인터페이스**: 화면 오른쪽 위 국기 버튼으로 인터페이스 언어를 바꿀 수 있어요.
- **모바일 대응**: 화면이 좁아지면 언어·레벨 선택이 드롭다운으로 바뀌고, 하단에 탭 내비게이션이 나타납니다.

## 사용 방법

1. `index.html` 또는 `lang_tutor.html` 파일을 더블클릭해서 브라우저로 열거나, 로컬 서버로 실행합니다.
   ```bash
   python3 -m http.server 8934
   ```
   위 명령을 실행한 뒤 `http://localhost:8934/index.html` (또는 `lang_tutor.html`)로 접속합니다.
2. 홈 화면에서 오늘 공부할 **언어**와 **레벨**을 선택합니다.
3. "오늘의 학습" 카드 중 하나(단어/문법/회화/듣기)를 눌러 학습을 시작합니다.
4. 각 학습을 끝까지 마치면 자동으로 복습 문제로 넘어가고, 복습까지 끝나면 완료 표시와 함께 축하 메시지가 나타납니다.
5. 4가지를 모두 마치면 홈 화면 진행률이 100%가 되고, 진행률 탭에서 학습 기록을 확인할 수 있어요.

## 데이터 저장 방식

- 모든 학습 진행 상황(선택한 언어, 레벨, 오늘 완료한 항목, streak, 학습 통계 등)은 브라우저의 `localStorage`에만 저장됩니다.
- 별도 로그인 없이 사용할 경우, 데이터는 **그 브라우저(그 기기)에서만** 유지됩니다. 다른 브라우저나 기기에서 열면 처음부터 다시 시작해요.
- 날짜가 바뀌면 오늘의 진행률과 완료 표시는 자동으로 초기화되고, streak은 어제도 학습했는지에 따라 유지되거나 초기화됩니다.

## 현재 상태 & 앞으로 계획

- 지금은 AI API나 로그인 없이 완전히 정적으로 동작해요 (콘텐츠가 파일 안에 고정되어 있음).
- `lang_tutor.html`은 앞으로 다음 두 가지를 추가로 연동할 예정입니다.
  - **Claude API 연동**: 사용자가 직접 자신의 API 키를 설정 화면에 입력하면(그 브라우저에만 저장), 학습 콘텐츠를 AI가 생성하도록 확장
  - **Firebase 로그인 + Firestore 연동**: Google/이메일 로그인을 붙이고, 로그인한 사용자의 학습 진행률과 설정을 클라우드에 저장해서 PC·모바일 등 여러 기기에서 동기화

## 기술 스택

- HTML5 / CSS3 / Vanilla JavaScript (프레임워크 없음)
- Web Speech API (브라우저 내장 음성 합성)
- (예정) Anthropic Claude API, Firebase Authentication, Firestore
