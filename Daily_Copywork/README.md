# ✍️ 매일 필사

PDF로 매일 20문장씩 필사(베껴 쓰기) 연습을 할 수 있는 웹 앱입니다.
설치나 서버 없이 브라우저에서 파일만 열면 바로 사용할 수 있습니다.

- **사용할 파일**: `daily_copywork.html` (이 파일을 열어서 사용하세요)
[Daily Copywork 바로가기](https://annaeun.github.io/coding_plus/Daily_Copywork/daily_copywork.html)
- `index.html`은 예전 버전을 보관해둔 백업용 파일입니다. 사용하지 않아도 됩니다.

## 시작하기

1. `daily_copywork.html` 파일을 더블클릭해서 브라우저(Chrome, Safari, Edge 등)로 엽니다.
2. 홈 화면 아래쪽 **"필사 원본 PDF"** 영역에 필사하고 싶은 PDF 파일을 끌어다 놓거나, 클릭해서 업로드합니다.
   - 텍스트가 포함된 PDF만 인식됩니다(스캔 이미지로만 된 PDF는 문장을 추출하지 못합니다).
   - PDF의 첫 페이지부터 순서대로 문장을 추출하며, 문장 앞에 붙은 번호(`1.`, `1)`, `(1)`, `①` 등)는 자동으로 제거됩니다.
3. 업로드가 끝나면 **"오늘 필사 시작하기"** 버튼을 눌러 필사를 시작합니다.

## 홈 화면 구성

| 요소 | 설명 |
|---|---|
| 진행률 바 | 전체 문장 중 지금까지 완료한 문장 수 / 퍼센트 |
| 연속 기록 카드 | "오늘까지 N일째 필사를 이어가고 있어요!" — 매일 이어가면 숫자가 올라가고, 하루라도 건너뛰면 "연속 기록이 끊겼어요"로 바뀌며 1부터 다시 시작합니다. (PDF를 바꿔도 이 기록은 유지됩니다) |
| 오늘의 필사 상태 카드 | 오늘 분량을 아직 안 했는지 / 완료했는지 / 놓쳤는지 보여줍니다 |
| 오늘 필사 다시하기 | 오늘 분량을 완료한 뒤에도 같은 문장으로 다시 연습할 수 있는 버튼 (노트만 비워지고 진행률은 그대로 유지됩니다) |
| 필사 원본 PDF | 현재 등록된 PDF 이름, 총 문장 수, 다른 PDF로 교체하는 버튼 |

> ⚠️ PDF를 다른 파일로 교체하면 지금까지의 진행률(진도, 연속 기록 제외)이 초기화됩니다. 교체 전 확인 메시지가 한 번 더 뜹니다.

## 매일 분량과 진도 규칙

- 하루 기본 분량은 **20문장**입니다.
- 완료 후 팝업의 **"다음 필사하기"**를 눌러 그날 안에 더 진행해도, 날짜는 항상 "오늘 완료"로만 기록됩니다. 다음 날에는 이미 미리 한 만큼을 감안해서 이어지는 새 분량이 생성됩니다(같은 내용이 중복되지 않습니다).
- 어느 날 분량을 완료하지 못하고 하루 이상 지나면, 다시 열었을 때 **"OO일치 필사를 놓쳤어요"** 안내와 함께 놓친 날 분량 + 오늘 분량이 하나로 합쳐진 필사 페이지가 자동으로 만들어집니다.

## 필사(책) 화면

- 책이 펼쳐진 모양으로, **왼쪽 페이지**에 오늘의 원문 문장이 번호와 함께 나열되고, **오른쪽 페이지**는 줄이 있는 노트입니다.
- 오른쪽 노트에 원문을 보고 그대로 옮겨 적으면:
  - 원문과 **같으면 검은색**, **다르면 빨간색**으로 실시간으로 표시됩니다.
  - 상단에 현재까지 입력한 내용 기준 **정확도(%)**가 표시됩니다.
- **정확도나 작성량과 관계없이** 언제든 **"오늘 필사 완료하기"** 버튼을 눌러 완료 처리할 수 있습니다.
- 완료 버튼을 누르면 "오늘도 필사 완료!" 팝업이 뜨고, 두 가지를 선택할 수 있습니다.
  - **확인**: 홈 화면으로 돌아갑니다.
  - **다음 필사하기**: 이어서 다음 20문장 필사로 넘어갑니다 (남은 문장이 없으면 이 버튼은 나타나지 않습니다).

## 로그인 / 데이터 보관

- 우측 상단 **"로그인"** 버튼을 누르면 Google / 이메일 로그인 화면이 나타나지만, 아직 실제 Firebase 연동 전이라 **"준비 중" 안내만 뜨고 로그인은 되지 않습니다.**
- 현재 모든 진행 상황(문장, 진도, 연속 기록 등)은 **이 브라우저의 localStorage**에만 저장됩니다. 즉,
  - 같은 컴퓨터의 같은 브라우저에서는 다시 열어도 이어서 할 수 있습니다.
  - 다른 컴퓨터/다른 브라우저/시크릿 모드에서는 데이터가 공유되지 않습니다.
  - 브라우저 데이터(캐시/사이트 데이터)를 지우면 진행 상황도 함께 사라집니다.
- 여러 기기에서 로그인으로 데이터를 동기화하려면 Firebase 프로젝트 연동 및 추가 개발이 필요합니다.

## 화면 크기 대응

- 데스크톱/태블릿 너비에서는 책이 좌우 두 페이지로 펼쳐지고, 화면이 커질수록 페이지도 함께 넓어집니다.
- 모바일 등 좁은 화면에서는 원문 페이지와 노트 페이지가 위아래로 쌓여서 보여집니다.
